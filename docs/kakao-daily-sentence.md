# 매일 한 문장 카톡 보내기 — 조사 결과 (2026-11-17)

## 한 줄 결론
"나에게 보내기"는 무료이고 건수 제한도 없지만, **카카오 문서에 "서비스가 사용자에게 메시지를 발송할 수 없습니다"라고 돼 있어요.**
그래서 서버가 매일 자동으로 보내는 용도로 쓰면 정책 위반으로 막힐 위험이 있어요.
→ **매일 자동 발송은 앱 푸시 알림으로**, 카톡은 **사용자가 직접 누르는 "카톡으로 보내기" 버튼**으로 쓰는 걸 추천해요.

## 공식 문서에서 확인한 것
| 항목 | 내용 |
|---|---|
| 필요한 동의 | `talk_message` (카카오톡 메시지 전송) + 카카오 로그인 |
| 비즈 앱·심사 | 나에게 보내기는 사용 권한 요구 없음 (친구에게 보내기만 비즈 앱·심사 필요) |
| 나에게 보내기 건수 | 심사 전후 모두 "발송 건수 제한 없음" |
| 친구에게 보내기 | 심사 전 하루 30건, 심사 후 앱 기준 하루 30,000건 (발신자당 100, 수신자당 100, 같은 쌍 20) |
| 요금 | 나에게 보내기 요금은 명시 없음 (사실상 무료). 유료 API 표에 "기본 템플릿 발송 50원/건"이 있으나 대상 불명확, 2026-02-02~2027-12-31 건당 10원 할인 |
| 메시지 모양 | 피드·리스트·텍스트 등 기본 템플릿, 버튼(웹/앱 링크) 넣기 가능 |
| 용도 | "같은 서비스 내 사용자간 메시지", "서비스가 사용자에게 메시지를 발송할 수 없습니다". 광고성은 채널·브랜드 메시지 등 다른 상품 안내 |
| 토큰 | 액세스: REST 6시간 / Android·iOS 12시간. 리프레시: 2달(1달 남으면 갱신 가능, 갱신 시 새 토큰으로 교체) |

## 선택지
1. **앱 푸시 알림 (추천, 무료)** — 매일 아침 "오늘의 문장" 알림. 앱스토어 앱(Capacitor)이면 쉽게 됨.
2. **"카톡으로 보내기" 버튼 (무료)** — 사용자가 문장 카드에서 누르면 내 카톡(나와의 채팅)으로 저장. 사용자가 직접 보내는 것이라 정책에 맞음.
3. **카카오톡 채널 메시지 / 브랜드 메시지 (유료)** — 매일 자동으로 카톡을 보내려면 이 정식 상품을 써야 함. 친구 수 × 건당 요금.
4. (비추천) 서버가 매일 "나에게 보내기"를 대신 호출 — 무료지만 위 문구에 걸릴 수 있음. 쓰려면 카카오 데브톡에 먼저 문의.

## 만드는 순서 (1 + 2)
1. 카카오 개발자 앱 등록 → 카카오 로그인 → `talk_message` 동의 추가
2. 문장 카드에 "카톡으로 보내기" 버튼 (피드 템플릿: 문장, 뜻, "앱에서 듣기" 버튼)
3. Capacitor 앱에 푸시 알림 + 매일 정해진 시간 알림 (Cloudflare Worker 예약 실행 또는 기기 로컬 알림)

## 확인 못 한 것
- 운영 정책 페이지(광고·자동 발송 금지 세부 문구)는 읽지 않았음
- 기본 템플릿 링크에 도메인 등록이 필요한지 명시 없음
