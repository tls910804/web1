# 코드 점검 보고서 (2026-11-22)

**이 저장소가 하는 일:** 문장 쇼츠(langshorts)는 휴대폰 브라우저에서 쓰는 언어 공부 웹앱(React + Vite)이에요. 문장 카드, 복습, AI 전화를 제공하고, 기록은 각 기기 안(localStorage)에만 저장해요. `ai-call-worker`는 AI 전화에서 대본에 없는 말에 한 문장으로 대답하는 작은 서버(Cloudflare Worker)예요. master에 push하면 GitHub Pages로 자동 배포돼요.
**가정한 사용량:** 앱은 한 기기에 한 사람, 서버는 하루 최대 3000번 대답이에요.
**확인한 것:** `npm test`와 `tsc --noEmit`은 둘 다 통과했어요. 11월 18일 보고서의 1번·3번은 아직 고쳐지지 않았어요.

## 꼭 고쳐야 해요

1. **연속 기록 숫자가 화면마다 달라요** (`src/screens/Review.tsx:162-165`, `src/lib/useActions.tsx:84`, `src/screens/Study.tsx:73`, `src/App.tsx:107-109`)
   - **무엇:** 연속 기록을 두 가지로 세요. 내 기록 화면은 복습·자동 공부·AI 전화로 세고, 복습 끝 화면과 공부 요약은 복습한 날만 세는 `state.streak`을 써요.
   - **문제:** 10일 동안 AI 전화만 하고 오늘 처음 복습하면 "10일 연속으로 복습했어요"라고 나와요. 실제 복습은 하루예요.
   - **고치는 법:** 숫자를 `streakOf(state.log)` 하나로 통일하고, 문구는 "N일 연속 공부"로 바꿔요. `state.streak`은 쓰지 않아요.
   - **안 고치면:** 같은 사람에게 화면마다 다른 숫자가 보여서 앱을 믿기 어려워져요.

2. **AI 대답이 실패해도 하루 횟수가 줄어요** (`ai-call-worker/src/index.ts:33-37`)
   - **무엇:** 서버는 AI를 부르기 전에 기기·IP·전체 횟수를 먼저 1씩 올려요.
   - **문제:** AI 쪽이 바쁘거나 오류가 나도 횟수는 이미 올라가 있어요. 장애가 길면 사용자는 대답을 한 번도 못 받고 하루 20번을 다 써요.
   - **고치는 법:** 횟수를 올리는 `put` 3개를 AI 응답이 성공한 뒤(`return json(...200...)` 바로 앞)로 옮겨요.
   - **안 고치면:** AI 장애가 나는 날 AI 대답이 없는 사용자가 생겨요.

3. **로그인 안내 문구가 사실과 달라요** (`src/lib/useActions.tsx:43`)
   - **무엇:** 첫 저장 직후 모든 사용자에게 뜨는 시트에 "로그인하면 다른 기기에서도 이어서 볼 수 있어요"라고 적혀 있어요.
   - **문제:** 지금 로그인은 데모라 이름만 저장하고, 서버에는 아무것도 보내지 않아요. 사용자는 클라우드에 저장된다고 믿고, 폰을 바꾸거나 브라우저 데이터를 지우면 기록을 모두 잃어요.
   - **고치는 법:** 문구를 "이 기기에 저장돼요. 기기를 바꿀 땐 데이터 내보내기를 쓰세요"로 바꾸거나, 진짜 동기화를 만들 때까지 로그인 시트를 숨겨요.
   - **안 고치면:** 사용자가 잘못된 믿음으로 기록을 잃을 수 있어요. 되돌릴 방법이 없어요.

4. **깨진 파일을 가져오면 기록이 통째로 지워질 수 있어요** (`src/screens/Sub.tsx:47-54`, `src/store.tsx:51-57,89`)
   - **무엇:** 가져오기는 파일에 `saved`와 `learn`이 배열이기만 하면 받아서 `{...state, ...incoming}`으로 합쳐요. 안의 항목 모양은 보지 않아요.
   - **문제:** 항목에 `id`가 없거나(`normalize`가 `item.id.split`에서 멈춤) `notify`가 null인 파일이면 화면이 멈춰요. `load()`는 오류가 나면 조용히 기본값으로 시작하고, 곧바로 그 빈 값을 같은 저장 키에 덮어써요. 예전 기록은 그대로 사라져요.
   - **고치는 법:** 가져오기에서 항목마다 `id`(문자열), `card.words`(배열)를 확인하고 틀리면 거절해요. `load()`는 오류가 나면 원본 글자를 `sentence-shorts-v1-broken`에 한 번 복사한 뒤 시작해요.
   - **안 고치면:** 손으로 고쳤거나 오래된 백업 파일 하나로 모든 기록을 잃을 수 있어요.

## 고치는 게 좋아요

5. **사이트에 올리지 않을 파일이 그대로 공개돼요** (`.github/workflows/pages.yml:39`)
   - **무엇:** 배포할 때 저장소 전체를 `_site`로 복사해요(`shorts-react`, `.git`, `.github`만 뺌). 저장소는 PUBLIC이에요.
   - **문제:** `langshorts.com/참고자료/…png`(다른 앱 화면 캡처 3장), `HANDOFF.md`, `docs/`, `tools/`(13MB), `ai-call-worker/`가 모두 주소로 열려요. `CLAUDE.md`의 "참고자료는 커밋에서 빼기" 규칙과도 어긋나요. 저장소에서 비밀키는 찾지 못했어요.
   - **고치는 법:** `rsync`에 `--exclude='참고자료' --exclude='docs' --exclude='tools' --exclude='ai-call-worker' --exclude='HANDOFF.md' --exclude='CLAUDE.md'`를 더해요. 참고자료는 `git rm -r --cached 참고자료`로 추적도 끊어요.
   - **안 고치면:** 남의 앱 캡처 이미지가 공개 사이트에 남고, 작업 메모가 노출돼요.

6. **배포 전에 테스트를 돌리지 않아요** (`.github/workflows/pages.yml:30-34`, `shorts-react/package.json`)
   - **무엇:** 배포 단계는 `npm ci`와 `npm run build`(타입 검사 포함)만 해요. `npm test`와 `ai-call-worker`의 `policy.test.ts`는 돌지 않아요.
   - **문제:** 새 문장 103개처럼 `cards.json`을 손으로 고칠 때, 카드 하나에 `words`가 빠지면 타입 검사를 통과하고 모든 사용자 앱이 멈춰요. `answer.test.ts`가 이런 모양을 일부 확인하지만 배포 전에 실행되지 않아요.
   - **고치는 법:** `npm run build` 앞에 `npm test` 한 줄을 넣어요. 실패하면 배포가 멈춰요.
   - **안 고치면:** 잘못된 문장 데이터가 그대로 배포돼요.

7. **복습 간격 계산과 데이터 변환에 테스트가 없어요** (`src/lib/srs.ts:6-21`, `src/store.tsx:36`)
   - **무엇:** `interval`, `rateResult`(좋음·어려움·다시에 따른 다음 복습일)과 `normalize`(예전 데이터 변환)는 복습의 핵심 계산이에요. `wrongNote`와 `streakInfo`만 테스트돼 있어요.
   - **문제:** `rateResult`를 잘못 고치면 모든 문장의 복습 날짜가 달라지는데 눈으로 알기 어려워요. `normalize` 실수는 업데이트 한 번에 저장 문장을 깨뜨려요.
   - **고치는 법:** `answer.test.ts`에 assert 5줄을 더해요(`rateResult('std', {step:0}, 'good')`의 step과 days, `again`이 step 0과 1일인지, 예전 단어 항목 하나가 `:e`로 바뀌는지).
   - **안 고치면:** 복습 계산 실수를 사용자가 먼저 발견해요.

8. **파일로 내보내기가 두 군데에 거의 같게 있어요** (`src/lib/backup.ts`, `src/lib/useActions.tsx:122-137`)
   - **무엇:** 같은 일(JSON 파일로 내보내기)을 하는 함수가 둘이에요. `useActions`의 것은 `lastBackup`을 상태에도 저장해요.
   - **문제:** 저장 공간이 꽉 찼을 때 뜨는 창(`App.tsx:97`)은 `backup.ts`를 써서 `lastBackup`을 상태에 남기지 않아요. 설정 화면은 "마지막 백업 없음"이라고 계속 말해요.
   - **고치는 법:** `backup.ts`를 지우고 `App.tsx`에서도 `exportData`를 써요. 약 12줄이 줄어요.
   - **안 고치면:** 같은 규칙이 두 곳에서 따로 변하고, 백업 표시가 틀려요.
