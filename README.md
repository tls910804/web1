# web1
## 문장 쇼츠 (`shorts/`)

한 문장씩 넘기며 배우는 외국어 앱. `shorts/index.html`을 브라우저에서 열면 됩니다.

- 둘러보기: 위로 넘기기, 파란 핵심 표현 탭 → 표현 시트, 두 번 탭해서 저장, 듣기·해석 가림·복사
- 배울래요: 문장 / 단어·표현 저장 목록, 외웠어요 표시, 복습 시작, 문장 직접 추가
- 복습: 정답 보기 → 다시 볼래요(내일) / 알았어요(3일 뒤), 완료 화면과 연속 복습 일수
- 언어: 내 언어 1개 + 배우는 언어 여러 개 선택

저장 내용은 브라우저 localStorage에 남습니다. 로그인 시트는 화면만 있는 데모입니다.
